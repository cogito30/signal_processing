# Chapter 12. 학습하는 FIR 필터: 1D CNN과 파이토치(PyTorch)의 등판

- 지금까지 우리는 험난한 신호처리의 산맥을 순수 파이썬과 넘파이(NumPy)라는 두 다리만으로 꿋꿋하게 넘어왔습니다. 8장에서는 싱크(Sinc) 함수를 이용해 노이즈를 깎아내는 정밀한 FIR 필터를 우리 손으로 직접 설계했죠.

- 하지만 전통적인 방식(DSP)에는 한계가 있습니다. "우리가 제거해야 할 노이즈가 정확히 50Hz라는 것을 미리 알고 있어야만" 필터를 짤 수 있다는 것입니다. 만약 강아지 짖는 소리와 고양이 우는 소리를 구분해야 한다면요? 어떤 주파수를 남기고 어떤 주파수를 잘라내야 할지, 인간의 머리로는 도저히 수식을 짜낼 수 없습니다.

- 이제 발상을 완전히 뒤집을 때가 왔습니다. 필터 배열을 사람이 수학으로 계산하는 대신, 컴퓨터가 수만 번의 시행착오를 거쳐 스스로 완벽한 필터 배열을 찾아내게(학습하게) 만들면 어떨까요?

- 이것이 바로 현대 딥러닝의 핵심이자, 이번 장에서 다룰 1차원 합성곱 신경망(1D CNN)의 진짜 정체입니다. 그리고 이 엄청난 계산을 대신해 줄 강력한 무기, 파이토치(PyTorch)가 드디어 등판합니다.

## 1. 위대한 깨달음: CNN의 '가중치'는 FIR의 '필터 배열'이다

- 딥러닝을 처음 배우는 사람들은 CNN(Convolutional Neural Network)이 마법의 상자인 줄 압니다. 하지만 3부에서 합성곱을 쌩코딩으로 짜본 여러분은 이미 CNN의 본질을 완벽하게 꿰뚫고 있습니다.

- 7장에서 배운 FIR 필터의 수식을 다시 떠올려 봅시다.

$$y[n] = \sum_{k=0}^{M-1} x[n-k] \cdot h[k]$$

- $x$: 들어오는 신호 배열
- $y$: 튀어나오는 결과 배열
- $h$: 우리가 직접 수식으로 깎아 만든 필터 배열 (예: 이동 평균, 로우패스)

- 놀랍게도, 파이토치의 1D CNN 수식은 위 수식과 토시 하나 틀리지 않고 완벽하게 똑같습니다.유일한 차이점은 딱 하나입니다. 딥러닝에서는 저 필터 배열 $h$를 사람이 깎지 않고, 처음에 '랜덤한 숫자'로 채워 넣은 뒤 오차를 줄이는 방향으로 조금씩 숫자를 수정해 나갑니다.

- 딥러닝 학계에서는 이 $h$를 필터 배열이라고 부르지 않고 멋지게 포장하여 **가중치(Weight)** 혹은 **커널(Kernel)** 이라고 부를 뿐입니다.

## 2. 미분의 고통과 오차 역전파 (Backpropagation)

- 그렇다면 컴퓨터는 $h$(가중치)를 어떻게 스스로 수정할까요?

1. 랜덤한 필터로 일단 신호를 합성곱해 봅니다. (순전파, Forward)
2. 정답(예: "이건 고양이 소리야!")과 비교해 봅니다. 당연히 처음엔 엉터리 결과가 나옵니다.
3. 오차(Loss)가 발생하면, 이 오차를 줄이기 위해 "필터 배열의 각 숫자를 늘려야 할까, 줄여야 할까?"를 고민합니다.

- 이때 필요한 수학이 바로 미분(Derivative)입니다. 오차를 가중치로 편미분하여 그 기울기(Gradient) 반대 방향으로 숫자를 업데이트하는 과정, 이것이 딥러닝의 꽃인 오차 역전파(Backpropagation)입니다.

- 문제는 이 역전파를 넘파이(NumPy)로 직접 짜려면 합성곱 수식의 미분 연쇄 법칙(Chain Rule)을 구하기 위해 칠판 가득 행렬 미분 수식을 적어야 한다는 것입니다. 행렬이 조금만 커져도 개발자의 정신이 아득해집니다.

## 3. 구원자의 등장: 파이토치(PyTorch)와 자동 미분
- 이 끔찍한 미분의 늪에서 우리를 구원하기 위해 파이토치(PyTorch)가 등장합니다.
- 파이토치는 우리가 순방향(Forward)으로 합성곱을 한 번 계산하기만 하면, 그 뒤에 숨겨진 복잡한 미분 계산을 loss.backward()라는 단 한 줄의 코드로 완벽하게 대신해 줍니다. 이를 **자동 미분(Autograd)** 이라고 합니다.

- 이제 수식의 고통은 파이토치에 넘기고, 우리는 '데이터의 흐름'과 '구조 설계'에만 집중하면 됩니다!

## 4. 전통과 현대의 결합 (Python 실습)
- 우리가 8장에서 만들었던 '정통 FIR 필터'를 파이토치의 '1D CNN 레이어'에 직접 이식해 보겠습니다. 
- 딥러닝의 `Conv1d`가 결국 우리가 알던 그 FIR 필터와 똑같은 녀석이라는 것을 내 눈으로 확인하는 가장 짜릿한 순간입니다.

```python
import torch
import torch.nn as nn
import numpy as np
import matplotlib.pyplot as plt

# --------------------------------------------------------
# 1. 테스트용 신호 만들기 (2Hz 원본 + 50Hz 노이즈)
# --------------------------------------------------------
fs = 1000
t = np.linspace(0, 1, fs, endpoint=False)
clean_signal = np.sin(2 * np.pi * 2 * t)
noisy_signal = clean_signal + 0.5 * np.sin(2 * np.pi * 50 * t)

# PyTorch는 numpy 배열 대신 'Tensor(텐서)'라는 자기만의 배열을 씁니다.
# CNN에 넣기 위해 형태를 [배치 크기, 채널 수, 신호 길이] = [1, 1, 1000] 으로 맞춥니다.
tensor_signal = torch.tensor(noisy_signal, dtype=torch.float32).view(1, 1, -1)

# --------------------------------------------------------
# 2. PyTorch 1D CNN 레이어 소환!
# --------------------------------------------------------
# in_channels=1 (오디오 모노), out_channels=1 (출력도 1개)
# kernel_size=101 (우리가 8장에서 만들었던 101개짜리 FIR 필터 길이와 동일)
cnn_layer = nn.Conv1d(in_channels=1, out_channels=1, kernel_size=101, padding='same', bias=False)

# --------------------------------------------------------
# 3. 8장의 FIR 로우패스 필터를 CNN 가중치(Weight)에 강제 주입!
# --------------------------------------------------------
# 8장에서 짰던 Sinc 함수 기반 로우패스 필터 로직 (간략화된 버전)
fc = 10 / fs
n = np.arange(101) - 50
fir_filter_array = np.sinc(2 * fc * n) * np.blackman(101) 
fir_filter_array = fir_filter_array / np.sum(fir_filter_array) # 정규화

# 우리의 수제 필터 배열을 파이토치 텐서로 변환하여 CNN 레이어의 가중치로 덮어씌웁니다.
with torch.no_grad():
    cnn_layer.weight.data = torch.tensor(fir_filter_array, dtype=torch.float32).view(1, 1, 101)

# --------------------------------------------------------
# 4. PyTorch 텐서로 합성곱 필터링 실행!
# --------------------------------------------------------
# cnn_layer()를 호출하는 순간, 내부적으로 우리가 7장에서 짠 슬라이딩 윈도우 연산이 일어납니다.
filtered_tensor = cnn_layer(tensor_signal)

# 결과를 다시 numpy 배열로 꺼내기
filtered_signal_pytorch = filtered_tensor.squeeze().detach().numpy()

# --------------------------------------------------------
# 5. 결과 확인
# --------------------------------------------------------
plt.figure(figsize=(12, 5))
plt.plot(t, noisy_signal, color='lightgray', label='Noisy Signal (Input to PyTorch)')
plt.plot(t, filtered_signal_pytorch, color='#d35400', linewidth=3, label='PyTorch 1D CNN Output')
plt.title("PyTorch Conv1d as a Traditional FIR Filter", fontsize=14)
plt.xlabel("Time (seconds)")
plt.legend(loc='upper right')
plt.tight_layout()
plt.show()
```

( 실행 결과의 의미 )
- 코드를 실행하면, 우리가 순수 넘파이로 만들었던 FIR 로우패스 필터링과 완벽하게 똑같이 50Hz 고주파 노이즈가 제거된 주황색 선형이 나타납니다.

- 이 실험이 증명하는 바는 명확합니다.
- 파이토치의 `nn.Conv1d`는 하늘에서 떨어진 마법이 아닙니다. 우리가 7~8장에서 지겹게 만들었던 그 '슬라이딩 윈도우 합성곱 배열'을 파이토치의 텐서(Tensor) 생태계 위에 올려놓은 것뿐입니다.

- 이제 우리는 파이토치에 내장된 이 필터($h$)를 미분(loss.backward())이라는 마법을 통해 '사람이 직접 세팅(강제 주입)하지 않고, 스스로 깎이도록' 만들 준비를 마쳤습니다.

## Summary
- 딥러닝 1D CNN의 가중치(Weight) 커널은 전통 신호처리의 **FIR 필터 배열** 과 물리적으로 완벽히 동일하다.
- 전통 신호처리는 수학자가 필터를 깎지만, 딥러닝은 오차 역전파(미분)를 통해 컴퓨터가 최적의 필터를 스스로 깎아낸다.
- PyTorch는 이 끔찍한 미분 노가다를 자동 미분(Autograd)으로 해결해 주는 아주 고마운 프레임워크다.
