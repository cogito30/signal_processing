# Chapter 04. 시간에서 주파수로: 푸리에 변환의 비밀은 '내적(Dot Product)'이다
- 신호처리 책을 펴서 **푸리에 변환(Fourier Transform)** 챕터에 도달하면, 대부분의 독자는 거대한 적분 기호와 자연상수 $e$, 그리고 허수 $i$가 뒤섞인 무시무시한 수식을 마주하고 책을 덮습니다.

- 하지만 이 수식의 껍데기를 한 꺼풀 벗겨내면, 그 안에는 초등학생도 이해할 수 있는 아주 직관적이고 아름다운 원리가 숨어 있습니다. 바로 '나와 똑같이 생긴 놈을 찾으면 소리치기(유사도 측정)'입니다.

- 이번 장에서는 복잡한 수학 공식 대신, 파이썬 배열의 내적(Dot Product)이라는 무기 하나만 들고 푸리에 변환의 심장부를 꿰뚫어 보겠습니다.

## 1. 시간의 세계 vs 주파수의 세계 (스무디의 레시피)
- 지금까지 우리가 1부에서 본 신호들은 모두 시간 축(Time Domain) 위에 그려졌습니다. '시간에 따라 파동이 어떻게 요동치는가'를 본 것이죠. 하지만 이 방식에는 치명적인 단점이 있습니다.

- 딸기, 바나나, 우유를 믹서기에 넣고 갈아버린 '스무디'를 상상해 보세요.
- 시간 축에서 신호를 본다는 것은 완성된 스무디의 색깔이나 맛을 보는 것과 같습니다. 반면, 주파수 축(Frequency Domain)에서 신호를 본다는 것은 "이 스무디 안에 딸기가 30%, 바나나가 50%, 우유가 20% 들어있다"라는 원래의 레시피(성분표)를 알아내는 것과 같습니다.

- 여러 주파수가 섞인 복잡한 소리 배열(스무디)에서, 특정 주파수(딸기)가 얼마나 들어있는지 어떻게 알아낼 수 있을까요?

## 2. 내적(Dot Product): 완벽한 '유사도 탐지기'
- 두 배열(신호)이 얼마나 닮았는지 알아내는 가장 확실한 수학적 방법은 **내적(Dot Product)** 입니다.
- 넘파이에서 내적은 두 배열의 같은 위치에 있는 원소끼리 곱한 뒤, 그 결과를 모두 더하는 `(np.sum(A * B))` 아주 단순한 연산입니다.

- 이 단순한 곱하기와 더하기가 왜 유사도 탐지기가 될까요?

1. 두 신호가 똑같이 생겼을 때 (닮음):
- A가 양수(+)로 솟구칠 때 B도 양수(+)이고, A가 음수(-)로 파고들 때 B도 음수(-)라면?
- $(+) \times (+) = (+)$ 이고, $(-) \times (-) = (+)$ 입니다. 즉, 곱해서 더할수록 결괏값은 폭발적으로 커집니다.

2. 두 신호가 전혀 다르게 생겼을 때 (안 닮음, 직교성):
- A와 B의 타이밍이 엇갈려서, 어떤 곳은 곱하면 $(+)$가 되고 어떤 곳은 곱하면 $(-)$가 된다면?
- 이 값들을 모두 더하는 과정에서 $(+)$와 $(-)$가 서로 상쇄되어 결괏값은 0(또는 0에 아주 가까운 수)이 되어버립니다.

- 이 성질(직교성, Orthogonality)이 바로 푸리에 변환의 모든 것입니다!

## 3. 주파수 사냥꾼 만들기
- 이제 이 원리를 코드로 직접 증명해 봅시다.
- 3Hz(저음) 파동과 7Hz(고음) 파동이 섞인 '정체불명의 미스터리 신호'를 만들겠습니다. 그리고 이 신호에 "혹시 너 안에 3Hz 있니?", "4Hz 있니?"라며 탐지기(테스트 사인파)를 찔러 넣어 내적을 구해볼 것입니다.

```python
import numpy as np
import matplotlib.pyplot as plt

# --------------------------------------------------------
# 1. 미스터리 신호 만들기 (스무디)
# --------------------------------------------------------
# 1초 동안 1000번 샘플링
t = np.linspace(0, 1, 1000, endpoint=False)

# 3Hz 신호(진폭 1.0)와 7Hz 신호(진폭 0.5)를 섞습니다.
mystery_signal = 1.0 * np.sin(2 * np.pi * 3 * t) + 0.5 * np.sin(2 * np.pi * 7 * t)

# --------------------------------------------------------
# 2. 주파수 탐지기 (내적 계산 함수)
# --------------------------------------------------------
def probe_frequency(target_signal, test_freq, time_array):
    """미스터리 신호 안에 특정 주파수(test_freq)가 얼마나 들어있는지 내적으로 검사합니다."""
    # 테스트할 주파수를 가진 순수 사인파를 만듭니다.
    test_wave = np.sin(2 * np.pi * test_freq * time_array)
    
    # 두 배열의 내적(Dot Product)을 구합니다. (element-wise 곱셈 후 총합)
    dot_product = np.sum(target_signal * test_wave)
    return dot_product

# --------------------------------------------------------
# 3. 탐지기로 미스터리 신호 찔러보기
# --------------------------------------------------------
print("=== 주파수 성분 검사 (내적 값) ===")
print(f"1Hz 검사 결과: {probe_frequency(mystery_signal, 1, t):.2f}")
print(f"3Hz 검사 결과: {probe_frequency(mystery_signal, 3, t):.2f} (Bingo!)")
print(f"4Hz 검사 결과: {probe_frequency(mystery_signal, 4, t):.2f}")
print(f"7Hz 검사 결과: {probe_frequency(mystery_signal, 7, t):.2f} (Bingo!)")
```

(결과 예시)
```
=== 주파수 성분 검사 (내적 값) ===
1Hz 검사 결과: -0.00
3Hz 검사 결과: 500.00 (Bingo!)
4Hz 검사 결과: 0.00
7Hz 검사 결과: 250.00 (Bingo!)
```

- 결과가 보이시나요? 미스터리 신호 안에 포함되어 있지 않은 1Hz나 4Hz를 찔러 넣었을 때는 내적 값이 완벽하게 0이 나옵니다. 반면, 포함되어 있던 3Hz를 넣자 500이라는 거대한 값이 튀어나오고, 7Hz를 넣었을 때는 250이 나옵니다. (진폭이 1.0과 0.5였으므로, 내적 값의 비율도 정확히 2:1로 나타납니다!)

## 4. DIY 푸리에 변환기 (Spectrum 직접 그려보기)
- 그렇다면, 이 내적 검사를 1Hz부터 10Hz까지 1Hz 단위로 반복해서(for 문) 그 결과를 그래프로 그리면 어떻게 될까요? 그것이 바로 여러분이 직접 만든 '푸리에 변환기'입니다!

```python
# 검사할 주파수 목록 (1Hz부터 10Hz까지)
test_frequencies = np.arange(1, 11)
similarity_scores = []

# for문을 돌며 모든 주파수에 대해 내적(유사도)을 계산합니다.
for freq in test_frequencies:
    score = probe_frequency(mystery_signal, freq, t)
    similarity_scores.append(score)

# 결과를 그래프(주파수 스펙트럼)로 그립니다.
plt.figure(figsize=(10, 4))
plt.stem(test_frequencies, similarity_scores, basefmt="k-", linefmt="#3498db", markerfmt="bo")
plt.title("My First Fourier Transform (Frequency Spectrum)")
plt.xlabel("Frequency (Hz)")
plt.ylabel("Similarity (Dot Product)")
plt.xticks(test_frequencies)
plt.show()
```

- 이 코드를 실행하면, X축이 '시간'이 아니라 '주파수(Hz)'로 바뀐 그래프가 나타납니다.
- 그래프를 보면 3Hz 위치에 거대한 막대가 서 있고, 7Hz 위치에 그 절반 크기의 막대가 서 있습니다. 나머지 주파수는 모두 바닥(0)에 붙어 있습니다.

- 축하합니다! 여러분은 방금 복잡한 수학 공식 없이, 섞여 있는 파동을 완벽하게 분리해 내는 주파수 스펙트럼(Spectrum)을 우리 손으로 직접 구현해 냈습니다.

## Summary
- 시간 도메인은 스무디의 결과물이고, 주파수 도메인은 스무디의 레시피(성분표)다.
- 내적(Dot Product, np.sum(A * B))은 두 배열이 얼마나 닮았는지(동기화되어 있는지) 측정하는 훌륭한 탐지기다.
- 푸리에 변환의 본질은 복잡한 신호에 여러 주파수의 사인파를 들이밀어 내적을 구하는 노가다(반복 작업)에 불과하다.

- 이제 푸리에 변환의 핵심 아이디어(내적)를 완벽히 이해했습니다. 하지만 위에서 만든 우리의 DIY 탐지기에는 치명적인 약점이 하나 있습니다. 신호의 타이밍(위상, Phase)이 조금만 어긋나도 내적 값이 0이 되어버린다는 점입니다.

- 이를 해결하기 위해 5장에서는 2차원 평면(복소수)을 도입하여, 완벽한 형태의 이산 푸리에 변환(DFT, Discrete Fourier Transform) 알고리즘을 쌩코딩으로 구현해 보겠습니다.
