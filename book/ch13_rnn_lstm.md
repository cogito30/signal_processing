# Chapter 13. 상태를 기억하는 IIR 필터의 진화: 끊임없이 이어지는 신호의 맥락 읽기 (RNN과 LSTM)

- 12장에서 우리는 과거의 데이터를 기억하지 않고 현재 들어온 신호 구간만 보고 판단하는 FIR 필터가 딥러닝의 1D CNN으로 진화하는 과정을 보았습니다.

- 하지만 9장을 떠올려 봅시다. 우리는 배열의 길이를 무식하게 늘리는 대신, 방금 계산한 자신의 출력값($y$)을 다시 입력으로 가져오는 '피드백(Feedback)' 구조를 통해 효율을 극대화한 **IIR 필터** 를 만들었습니다.

- 주식 가격, 심장 박동(ECG), 그리고 우리의 목소리처럼 '시간의 흐름(Sequence)'이 중요한 신호들은 과거의 맥락을 기억하는 능력이 필수적입니다. 이 IIR 필터의 피드백 구조를 딥러닝의 세계로 고스란히 가져온 모델, 그것이 바로 순환 신경망(RNN, Recurrent Neural Network)입니다.

## 1. IIR 필터와 RNN의 완벽한 평행이론
- 딥러닝의 복잡한 구조도 결국 우리가 짰던 전통 신호처리의 뼈대 위에 있습니다. 두 모델의 뼈대 수식을 나란히 비교해 보면 소름 돋는 평행이론을 발견할 수 있습니다.

1. 전통적인 IIR 필터 (9장)

$$y[n] = (b \cdot x[n]) + (a \cdot y[n-1])$$

- 현재 입력 $x[n]$에 계수 $b$를 곱하고, 직전 과거의 출력 $y[n-1]$에 피드백 계수 $a$를 곱해 더합니다.

2. 순환 신경망 (RNN)

$$h_t = \tanh(W_{ih} \cdot x_t + W_{hh} \cdot h_{t-1} + bias)$$

- 현재 입력 $x_t$에 가중치 행렬 $W_{ih}$를 곱하고, 직전 과거의 상태 $h_{t-1}$에 가중치 행렬 $W_{hh}$를 곱해 더한 뒤, $\tanh$라는 찌그러뜨리는 함수(활성화 함수)를 통과시킵니다.

- 놀랍게도 구조가 완전히 똑같습니다!
- RNN에서 말하는 은닉 상태(Hidden State, $h_t$)는 IIR 필터의 과거 출력값($y[n-1]$)과 정확히 같은 역할을 합니다. 차이가 있다면, 사람이 수식으로 $a, b$를 계산하는 대신 RNN은 수많은 오디오 데이터를 들려주며 오차 역전파(미분)를 통해 $W_{ih}$와 $W_{hh}$를 스스로 학습한다는 점입니다.

## 2. 바닐라 RNN의 한계: 메아리가 사라지다 (기울기 소실)

- 하지만 가장 기본적인 형태의 바닐라(Vanilla) RNN에는 치명적인 결함이 있습니다.
- 9장에서 IIR 필터를 설계할 때 피드백 계수 $a$가 1보다 크면 소리가 무한히 증폭(발산)되어 찢어지는 하울링이 생기고, 1보다 너무 작으면 메아리가 금방 사라진다는 것을 배웠습니다.

- RNN도 마찬가지입니다. 역전파를 통해 과거로 오차를 전달하며 가중치를 업데이트해야 하는데, 1보다 작은 가중치가 계속 곱해지다 보니 과거로 갈수록 그 값이 $0$에 수렴해 버립니다. 이를 기울기 소실(Vanishing Gradient)이라고 부릅니다.

- 결과적으로 바닐라 RNN은 "1초 전에 들은 소리는 기억하지만, 10초 전에 들은 소리는 까맣게 잊어버리는" 심각한 단기 기억 상실증에 걸리게 됩니다. 긴 오디오 파형이나 긴 심전도 데이터를 분석할 때는 도저히 써먹을 수가 없었죠.

## 3. 스마트 밸브의 등장: LSTM (Long Short-Term Memory)
- 이 단기 기억 상실증을 치료하기 위해 공학자들은 아주 기발한 장치를 고안해 냅니다. 기존 RNN에 컨베이어 벨트 역할을 하는 '셀 상태(Cell State, $C_t$)'라는 전용 기억 장치를 하나 더 뚫어준 것입니다.

- 그리고 이 컨베이어 벨트 위에 정보를 얼마나 올리고 내릴지 조절하는 스마트 밸브(Gate) 3개를 설치했습니다.

1. 망각 게이트 (Forget Gate): "과거의 기억 중 쓸모없는 노이즈는 버리자!" (0을 곱해 삭제)
2. 입력 게이트 (Input Gate): "지금 들어온 새로운 신호 중 중요한 특징만 기억에 추가하자!"
3. 출력 게이트 (Output Gate): "업데이트된 기억을 바탕으로, 다음 스텝에 넘겨줄 최종 결과만 뱉어내자!"

- 이 문(Gate)들 덕분에 LSTM은 수천 샘플 이전의 중요한 신호(예: 문장의 첫 단어, 특정 심장 박동 패턴)를 잊어버리지 않고 끝까지 끌고 갈 수 있게 되었습니다. 현재 시계열 신호처리와 오디오 분야에서 가장 널리 쓰이는 표준 뼈대가 바로 이 LSTM입니다.

## 4. PyTorch로 경험하는 LSTM의 위력 (Python 실습)
- 9장에서 우리는 과거의 상태를 기억하기 위해 복잡한 for문을 돌리며 피드백 값들을 일일이 배열에 더해주었습니다. 하지만 파이토치에서는 이 모든 과정이 nn.LSTM이라는 하나의 블록 안에 우아하게 추상화되어 있습니다.

- 사인파 신호를 차례대로 입력받아, 그 신호의 패턴을 기억하고 다음을 예측하는 기초적인 LSTM 구조를 확인해 보겠습니다.

```python
import torch
import torch.nn as nn
import numpy as np

# --------------------------------------------------------
# 1. 시계열(신호) 데이터 준비
# --------------------------------------------------------
# PyTorch RNN/LSTM의 기본 입력 형태는 3차원 텐서입니다: 
# [배치 크기(Batch), 시퀀스 길이(Time steps), 입력 특징 수(Features)]
# 예: 1개의 오디오 샘플, 100번의 시간 흐름, 매 시간마다 1개의 진폭 값
seq_length = 100
t = np.linspace(0, 2*np.pi, seq_length)
signal = np.sin(t)

# (1, 100, 1) 형태의 FloatTensor로 변환
x_tensor = torch.tensor(signal, dtype=torch.float32).view(1, seq_length, 1)

# --------------------------------------------------------
# 2. LSTM 모델 뼈대 세우기
# --------------------------------------------------------
class SignalLSTM(nn.Module):
    def __init__(self, input_size=1, hidden_size=16):
        super(SignalLSTM, self).__init__()
        
        # LSTM 층: 1개의 입력(진폭)을 받아 16개의 숨겨진 상태(메모리)로 확장합니다.
        # batch_first=True 로 설정하면 입력 텐서의 첫 번째 차원이 배치(Batch)가 됩니다.
        self.lstm = nn.LSTM(input_size=input_size, 
                            hidden_size=hidden_size, 
                            batch_first=True)
        
        # 16개의 메모리 정보를 다시 1개의 예측된 진폭 값으로 모아주는 선형(Linear) 층
        self.fc = nn.Linear(hidden_size, 1)

    def forward(self, x):
        # 1. LSTM 통과
        # out: 모든 시간(Time steps)에 대한 결과값
        # (h_n, c_n): 가장 마지막 시간의 은닉 상태(Hidden)와 셀 상태(Cell)
        out, (h_n, c_n) = self.lstm(x)
        
        # 2. 최종 결과 예측 (모든 시간에 대해 선형 층 통과)
        predictions = self.fc(out)
        return predictions

# --------------------------------------------------------
# 3. 모델에 신호 통과시키기
# --------------------------------------------------------
model = SignalLSTM()
print("입력 텐서의 형태:", x_tensor.shape) # [1, 100, 1]

# 미분(학습) 없이 순전파(Forward)만 테스트
with torch.no_grad():
    output_tensor = model(x_tensor)
    
print("출력 텐서의 형태:", output_tensor.shape) # [1, 100, 1]
```

( 코드의 핵심 포인트 )
- out, (h_n, c_n) = self.lstm(x) 이 단 한 줄이 실행될 때, 파이토치 내부에서는 우리가 9장에서 직접 짰던 for 문이 100번(seq_length) 돌면서 데이터를 순차적으로 집어삼킵니다.

- 과거의 상태를 h_n과 c_n에 계속 누적해가며 신호의 맥락을 파악하고, 그 기억을 바탕으로 현재의 값을 부드럽게 조정해 내는 완벽한 학습형 피드백 필터가 완성된 것입니다.

## Summary
- 전통 IIR 필터의 피드백($y[n-1]$) 구조는 딥러닝에서 RNN의 은닉 상태($h_{t-1}$)로 그대로 계승되었다.
- 기본 RNN은 과거의 정보를 쉽게 잊어버리는 기울기 소실 문제가 있어, 긴 오디오 파형을 분석하기 어렵다.
- 이를 해결하기 위해 스마트 밸브(Gate)와 컨베이어 벨트(Cell State)를 도입하여 장기 기억력을 부여한 모델이 LSTM이다.
