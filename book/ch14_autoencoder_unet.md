# Chapter 14. 신호의 노이즈를 지우는 마법: 오토인코더(Autoencoder)와 U-Net
- 8장에서 우리는 특정 주파수(예: 50Hz)를 칼같이 잘라내는 FIR 필터를 설계했습니다. 하지만 현실 세계의 문제는 수학 공식처럼 깔끔하지 않습니다.

- 카페에서 녹음한 내 목소리(Voice)와 뒤에서 들리는 사람들의 웅성거림(Noise)은 주파수 대역이 완전히 겹쳐 있습니다. 웅성거림을 지우겠다고 필터를 씌우면 내 목소리까지 뭉텅이로 깎여나가 먹먹해져 버리죠.

- 주파수만으로는 도저히 분리할 수 없는 이 악조건을 해결하기 위해, 딥러닝은 '데이터의 의미와 패턴'을 통째로 압축했다가 복원하는 아주 기발한 구조를 만들어냅니다. 그것이 바로 **오토인코더(Autoencoder)**  와 그 완성형인 **U-Net** 입니다.

## 1. 모래알과 다이아몬드: 오토인코더의 '병목(Bottleneck)'

- 오토인코더의 원리는 모래(노이즈)와 다이아몬드(음성)가 섞인 흙더미를 아주 좁은 체(Sieve)에 통과시키는 것과 같습니다.

- 구조는 크게 세 부분으로 나뉩니다.
1. 인코더 (Encoder): 입력된 신호의 배열 크기를 절반, 또 절반으로 계속 줄여나갑니다. (다운샘플링)
2. 병목 (Bottleneck): 배열이 가장 작게 압축된 구간입니다. 정보를 담을 공간이 턱없이 부족해집니다.
3. 디코더 (Decoder): 압축된 배열을 다시 두 배, 네 배로 뻥튀기하여 원래 크기로 복원합니다. (업샘플링)

- 왜 굳이 좁은 병목을 통과시킬까요?
- 공간이 부족해지면, 인공지능은 생존을 위해 '가장 중요하고 규칙적인 패턴(다이아몬드 = 사람의 목소리)'만 억지로 기억하고, '불규칙하고 자잘한 패턴(모래알 = 백색 잡음)'은 기억할 공간이 없어 그냥 버리게 됩니다.

- 이 상태에서 디코더를 통해 신호를 다시 원래 길이로 복원하면, 신기하게도 노이즈가 깔끔하게 증발해 버린 깨끗한 목소리만 복원되어 나타납니다.

## 2. 먹먹한 소리의 해결사: 스킵 커넥션 (Skip Connection)

- 오토인코더는 노이즈를 잘 지우지만 치명적인 단점이 있습니다. 좁은 병목을 억지로 통과하다 보니, 목소리의 미세한 디테일(고음역대의 선명함, 발음의 찰짐)까지 함께 버려져서 출력된 소리가 솜이불을 덮어쓴 것처럼 먹먹해진다는 것입니다.

- 이 잃어버린 디테일을 살려내기 위해 의료용 이미지 분할에서 처음 등장했던 전설적인 아키텍처, U-Net이 등판합니다.

- 알파벳 'U'자 모양을 닮은 이 모델의 핵심은 스킵 커넥션(Skip Connection, 연결 다리)입니다.
- 인코더에서 배열을 압축하기 직전의 싱싱한 원본 데이터를, 반대편 디코더에서 배열을 복원하는 단계로 곧바로 '복사+붙여넣기' 해버립니다.
  - 디코더의 고민: "아, 압축된 정보만 가지고 원래 소리를 선명하게 복원하려니 너무 헷갈리네."
  - 스킵 커넥션의 도움: "야! 내가 압축하기 전의 원본 스케치(고해상도 특징) 가져왔어! 이거 보고 힌트 얻어서 선명하게 색칠해!"

- 이 다리 하나를 놓아준 덕분에, U-Net은 노이즈는 기가 막히게 지우면서도 원본 목소리의 쨍한 디테일은 완벽하게 유지하는 오디오 딥러닝계의 마스터키가 되었습니다.

## 3. 밑바닥부터 짜는 1D U-Net (Python 실습)
- 복잡해 보이지만, 파이토치(PyTorch)를 사용하면 1D CNN과 torch.cat(텐서 이어 붙이기) 연산만으로 U-Net의 뼈대를 아주 우아하게 구현할 수 있습니다.

- 크기를 줄이는 Conv1d와 크기를 다시 늘려주는 ConvTranspose1d를 결합해 초미니 U-Net을 쌩코딩해 보겠습니다.

```python
import torch
import torch.nn as nn

class MiniUNet1D(nn.Module):
    def __init__(self):
        super(MiniUNet1D, self).__init__()
        
        # ----------------------------------------------------
        # 1. 인코더 (Encoder) : 배열 크기를 반으로 줄임
        # stride=2 옵션이 윈도우를 두 칸씩 뜀뛰기하게 만들어 크기를 절반으로 압축합니다.
        # ----------------------------------------------------
        self.encoder = nn.Conv1d(in_channels=1, out_channels=16, kernel_size=4, stride=2, padding=1)
        
        # ----------------------------------------------------
        # 2. 디코더 (Decoder) : 배열 크기를 다시 두 배로 늘림
        # ConvTranspose1d는 압축된 텐서를 뻥튀기(Up-sampling)하는 특수 레이어입니다.
        # ----------------------------------------------------
        self.decoder = nn.ConvTranspose1d(in_channels=16, out_channels=16, kernel_size=4, stride=2, padding=1)
        
        # ----------------------------------------------------
        # 3. 최종 출력층 (Final Layer)
        # 스킵 커넥션으로 원본(1채널)과 디코더(16채널)가 합쳐져 총 17채널이 들어옵니다.
        # 이를 다시 1채널짜리 깔끔한 소리 배열로 합칩니다.
        # ----------------------------------------------------
        self.final_conv = nn.Conv1d(in_channels=17, out_channels=1, kernel_size=3, padding=1)
        
    def forward(self, x):
        # x의 형태: [배치, 채널(1), 신호 길이(예: 1000)]
        
        # [Step 1] 인코딩: 좁은 병목으로 밀어 넣기
        enc = self.encoder(x)
        enc = torch.relu(enc) # 크기가 500으로 줄어들고 특징은 16개로 늘어남
        
        # [Step 2] 디코딩: 다시 원래 길이로 복원하기
        dec = self.decoder(enc)
        dec = torch.relu(dec) # 크기가 다시 1000으로 복원됨
        
        # [Step 3] 마법의 스킵 커넥션 (Skip Connection)
        # 원본 신호 'x'와 복원된 신호 'dec'를 채널(dim=1) 방향으로 이어 붙입니다.
        # "노이즈가 지워진 뼈대(dec)" + "선명한 원본 디테일(x)" 의 만남!
        merged = torch.cat([x, dec], dim=1) 
        
        # [Step 4] 최종 융합 및 출력
        out = self.final_conv(merged)
        return out

# --------------------------------------------------------
# 텐서 흐름(Shape) 테스트
# --------------------------------------------------------
# 가상의 노이즈 낀 오디오 신호 (배치 1, 모노 채널 1, 샘플 1024개)
noisy_audio = torch.randn(1, 1, 1024)

# 우리가 만든 U-Net에 통과시키기
model = MiniUNet1D()
clean_audio = model(noisy_audio)

print(f"입력 노이즈 신호 크기: {noisy_audio.shape}")
print(f"출력 복원 신호 크기: {clean_audio.shape} (크기 완벽 유지!)")
```


(딥러닝 시계열 처리의 정수)
- 위 코드는 단 한 번만 줄였다가 늘리는 '초미니' 버전이지만, 실제 현업에서 쓰이는 오디오 분리 모델(Demucs 등)은 이 `encoder-decoder` 블록을 6~8번씩 반복하여 소리를 무자비하게 압축했다가 스킵 커넥션을 촘촘하게 연결해 살려내는 구조를 가집니다.

- 우리는 방금 그 거대한 최첨단 모델들의 심장부를 30줄도 안 되는 코드로 완벽하게 관통했습니다.

## Summary
- 오토인코더(Autoencoder)는 데이터를 좁은 병목으로 강제 통과시켜, 규칙적인 패턴(음성)만 기억하고 불규칙한 패턴(노이즈)은 버리게 만드는 영리한 압축-복원 구조다.
- 하지만 압축 과정에서 손실된 미세한 디테일을 살리기 위해, 인코더의 원본 데이터를 디코더로 직행시키는 스킵 커넥션(Skip Connection)이 필요하다.
- 이를 적용한 U-Net 구조는 신호의 노이즈 캔슬링과 음원 분리(BGM과 보컬 분리) 분야에서 가장 강력한 베이스라인으로 활약하고 있다.
