# Chapter 10. 시간에 따른 주파수 변화 (STFT와 스펙트로그램): 소리를 사진으로 찍다

- 지금까지 우리는 1~3부에 걸쳐 신호를 시간에 따라 관찰하고(배열), 주파수로 분해하고(FFT), 원하는 부분을 잘라내는(필터링) 기술을 완벽히 마스터했습니다.

- 이제 우리는 이 책의 가장 중요한 전환점, 전통 신호처리와 현대 딥러닝(AI)이 만나는 교차로에 서 있습니다. 딥러닝(특히 CNN)은 2차원 '이미지'를 다루는 데 기가 막힌 재능이 있습니다. 그렇다면 1차원인 소리(배열)를 어떻게 2차원 이미지로 바꿀 수 있을까요?

- 이번 장에서는 1차원 오디오 배열을 화려한 2차원 열화상 카메라 사진처럼 변환해 주는 마법, STFT(단시간 푸리에 변환)와 스펙트로그램(Spectrogram)을 오직 넘파이(`numpy`) 배열 슬라이싱과 `for`문만으로 바닥부터 조립해 보겠습니다.


## 1. FFT의 치명적인 약점: "언제" 소리가 났는가?

- 6장에서 만든 고속 푸리에 변환(FFT)은 완벽해 보이지만, 아주 치명적인 약점이 하나 있습니다. 시간 정보를 완전히 잃어버린다는 것입니다.

- 피아노로 '도-미-솔'을 순서대로 친 3초짜리 녹음 파일과, '솔-미-도'를 거꾸로 친 3초짜리 녹음 파일이 있다고 해봅시다.
- 이 두 파일을 FFT에 통과시키면 결과가 어떻게 나올까요?

- 놀랍게도 두 파일의 주파수 스펙트럼(성분표)은 완벽하게 똑같이 나옵니다!
- FFT는 "이 3초 안에 도, 미, 솔이 들어있네!"라는 성분은 기가 막히게 찾아내지만, "그래서 '도'가 0초에 나왔어, 2초에 나왔어?"라는 질문에는 대답하지 못합니다. 믹서기로 과일을 갈아버린 스무디처럼 시간의 흐름이 완전히 박살 나버렸기 때문입니다.


## 2. 해결책: 잘게 쪼개서 분석하자 (STFT)

- 시간 정보를 살리면서 주파수도 알고 싶다면 어떻게 해야 할까요? 초등학생도 떠올릴 수 있는 아주 직관적인 해결책이 있습니다.
- "전체를 한 번에 갈아버리지 말고, 소리를 아주 짧게 깍둑썰기(Slice)해서 조각마다 따로 FFT를 돌리면 되잖아?"

- 이것이 바로 **단시간 푸리에 변환(Short-Time Fourier Transform, STFT)** 의 핵심 아이디어입니다.

1. 긴 소리 배열을 짧은 윈도우(예: 0.02초)로 싹둑 자른다.
2. 그 짧은 조각에 FFT를 적용해 주파수를 분석한다.
3. 윈도우를 조금씩 오른쪽으로 미끄러뜨리며(슬라이딩) 1~2번을 반복한다.
4. 조각들의 분석 결과를 시간순으로 차곡차곡 이어 붙인다.

- 우리는 이미 7장에서 합성곱(Convolution)을 배울 때 '슬라이딩 윈도우(Sliding Window)'의 개념을 마스터했습니다. 그 지식을 그대로 가져다 쓰기만 하면 됩니다!

## 3. 디테일 챙기기: 윈도우 함수와 겹치기 (Overlap)
- 하지만 배열을 가위로 싹둑 자를 때는 두 가지 부작용이 생기기 때문에 안전장치가 필요합니다.

1. **가장자리의 파열음 (Windowing)**: 파동을 중간에 강제로 싹둑 자르면, 잘린 단면이 날카로운 절벽처럼 변하면서 원래 없던 고주파 노이즈(Aliasing)가 발생합니다. 이를 막기 위해 조각의 양끝을 0으로 스르륵 줄여주는 둥근 덮개, 즉 해닝 윈도우(Hanning Window)를 덮어씌워 부드럽게 만들어야 합니다.
2. **정보 손실 막기 (Overlap)**: 해닝 윈도우를 씌우면 양끝 데이터가 0에 가까워져 정보를 잃게 됩니다. 이를 방지하기 위해, 조각을 자를 때 뚝뚝 끊어서 자르지 않고 보통 50%나 75%씩 서로 겹치게(Overlap) 자릅니다. (건축에서 기왓장을 얹는 모습과 같습니다.)

## 4. 밑바닥부터 짜는 STFT와 스펙트로그램 (Python 실습)
- `librosa`나 `torchaudio`의 블랙박스 함수(`librosa.stft`)에 의존하지 않고, 순수 파이썬 로직으로 STFT를 짜고 스펙트로그램 이미지를 생성해 보겠습니다.

```python
import numpy as np
import matplotlib.pyplot as plt

def my_stft(signal, n_fft=2048, hop_length=512):
    """
    1차원 신호를 입력받아 2차원 스펙트로그램 행렬을 반환하는 함수입니다.
    
    Args:
        signal: 1차원 오디오 배열
        n_fft: 깍둑썰기 할 조각의 크기 (Window Size)
        hop_length: 윈도우가 한 번에 미끄러질 이동 거리 (Overlap을 결정)
    """
    # 1. 조각의 양끝을 부드럽게 깎아줄 둥근 덮개(Hanning Window) 생성
    window = np.hanning(n_fft)
    
    # 2. 2차원 결과를 차곡차곡 쌓을 빈 리스트
    spectrogram = []
    
    # 3. 배열 위를 미끄러지는 슬라이딩 윈도우 (for문)
    # 0부터 신호의 끝까지, hop_length(512) 보폭으로 이동합니다.
    for i in range(0, len(signal) - n_fft, hop_length):
        
        # 1차원 조각(Chunk) 잘라내기
        chunk = signal[i : i + n_fft]
        
        # 둥근 덮개(Window) 씌우기 -> 양끝 데이터가 스르륵 0으로 떨어짐
        windowed_chunk = chunk * window
        
        # 조각에 대해 FFT 수행 (np.fft.rfft는 실수 신호의 중복된 절반을 버려줍니다)
        fft_result = np.fft.rfft(windowed_chunk)
        
        # 복소수에서 크기(Magnitude)만 추출
        magnitude = np.abs(fft_result)
        
        # 리스트에 추가 (한 줄짜리 주파수 성분표가 차곡차곡 쌓임)
        spectrogram.append(magnitude)
        
    # 4. 쌓인 리스트를 2차원 넘파이 행렬로 변환 후 전치(Transpose: T)
    # (시간을 X축, 주파수를 Y축으로 만들기 위해 행과 열을 바꿈)
    spectrogram_matrix = np.array(spectrogram).T
    
    return spectrogram_matrix
```

- 불과 10줄 남짓한 코드로 딥러닝 음성 인식 모델들의 뼈대인 STFT 알고리즘을 완벽하게 구현했습니다!

## 5. 사람의 귀를 흉내 내는 데시벨(dB) 변환
- 코드를 시각화하기 전에 마지막으로 하나만 짚고 넘어갑시다. 사람의 귀는 소리의 크기를 '선형적(덧셈)'으로 느끼지 않고 '로그(Log, 곱셈) 스케일'로 느낍니다.

- 작은 소리의 변화에는 아주 민감하지만, 큰 소리의 변화에는 둔감합니다. 그래서 스펙트로그램의 크기 값을 그대로 이미지로 그리면, 가장 큰 소리 몇 개만 번쩍이고 나머지는 까맣게 묻혀서 아무것도 보이지 않습니다.

- 이를 해결하기 위해 넘파이 행렬 전체에 로그(Log)를 씌워 데시벨(dB) 단위로 변환해 줍니다.
- 수식: $20 \times \log_{10}(\text{Magnitude})$

```python
# --------------------------------------------------------
# 테스트: 주파수가 점점 올라가는 소리(Chirp 신호) 만들어보기
# --------------------------------------------------------
fs = 16000 # 16kHz 샘플링
t = np.linspace(0, 2, fs * 2) # 2초 길이

# 처음엔 100Hz였다가 끝날 때 4000Hz로 점점 올라가는 새소리 같은 파동
signal_chirp = np.sin(2 * np.pi * (100 + 1950 * t) * t)

# --------------------------------------------------------
# 우리가 만든 STFT 실행 및 데시벨(dB) 변환
# --------------------------------------------------------
# STFT 행렬 획득! (2차원 Array)
spec_matrix = my_stft(signal_chirp, n_fft=1024, hop_length=256)

# 로그를 씌워 데시벨(dB)로 변환 (log10 안이 0이 되면 에러가 나므로 아주 작은 값 1e-10을 더해줌)
spec_db = 20 * np.log10(spec_matrix + 1e-10)

# --------------------------------------------------------
# 2차원 이미지(Spectrogram)로 시각화
# --------------------------------------------------------
plt.figure(figsize=(12, 6))

# pcolormesh나 imshow를 이용해 2차원 행렬을 열화상 카메라 사진처럼 그립니다.
plt.imshow(spec_db, aspect='auto', origin='lower', cmap='magma', 
           extent=[0, 2, 0, fs/2])

plt.colorbar(format='%+2.0f dB', label='Magnitude (dB)')
plt.title("My First Spectrogram (From Scratch!)", fontsize=16)
plt.xlabel("Time (seconds)", fontsize=12)
plt.ylabel("Frequency (Hz)", fontsize=12)
plt.tight_layout()
plt.show()
```
(감동적인 최종 결과물)
- 코드를 실행하면 아주 아름다운 열화상(Magma) 색상의 사진이 화면에 나타납니다!
- X축(시간)이 0초에서 2초로 흐르는 동안, Y축(주파수)의 밝게 빛나는 노란색 선이 100Hz에서 시작해 4,000Hz까지 사선으로 쭈욱 올라가는 모습을 눈으로 똑똑히 볼 수 있습니다.

- 단순히 1차원 숫자의 나열이었던 소리가, 컴퓨터 비전(CNN) 모델이 씹어먹기 가장 좋아하는 완벽한 2차원 이미지 특징(Feature) 맵으로 변신한 것입니다.

## Summary
- STFT는 긴 신호를 짧은 창문(Window) 단위로 쪼개고 미끄러뜨리며 FFT를 반복 수행하는 과정이다.
- 쪼갤 때 생기는 부작용을 막기 위해 해닝 윈도우(Hanning)를 씌우고 서로 겹치게(Overlap) 자른다.
- STFT 결과를 2차원 행렬로 쌓고 로그(dB)를 취한 이미지가 바로 스펙트로그램(Spectrogram)이다.
