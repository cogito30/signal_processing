# 5장. 이산 푸리에 변환(DFT) 직접 구현하기: 허수(j)가 쏘아 올린 기적

- 4장에서 우리는 내적(Dot Product)이라는 무기를 들고 주파수를 사냥하는 법을 배웠습니다. 하지만 우리가 만든 'DIY 주파수 탐지기'에는 아주 치명적인 결함이 하나 숨어있었습니다.

- 바로 위상(Phase)의 함정입니다. 이번 장에서는 이 함정이 무엇인지 파헤치고, 수학 역사상 가장 아름다운 공식인 **오일러의 공식** 과 **허수(Complex Number)** 를 도입하여 어떠한 상황에서도 절대 실패하지 않는 완벽한 주파수 분석기, **이산 푸리에 변환(DFT, Discrete Fourier Transform)** 을 밑바닥부터 구현해보겠습니다.

## 1. DIY 탐지기의 치명적 결함: 엇갈린 타이밍

- 4장에서 우리는 타겟 신호에 '사인파(Sine)'를 들이밀어 내적을 구했습니다. 만약 타겟 신호가 우리가 들이민 사인파와 완벽하게 겹친다면 내적 값은 폭발적으로 증가합니다.

- 그런데, 만약 타겟 신호가 주파수는 완벽히 똑같은데 시작 타이밍만 90도 어긋난 코사인파(Cosine)라면 어떻게 될까요?
  - 사인파와 코사인파는 서로 직교(Orthogonal)합니다.
  - 주파수가 같더라도, 이 둘을 내적 하면 (+)와 (-) 영역이 정확히 상쇄되어 결괏값이 0이 되어버립니다!

- 즉, 분명히 3Hz짜리 소리가 스무디 안에 들어있는데도, 타이밍이 어긋났다는 이유만으로 우리의 탐지기는 "3Hz는 없습니다(0)"라고 거짓말을 하게 됩니다.

## 2. 해결책: 사인과 코사인의 '쌍끌이 어선'

- 도망가는 3Hz를 완벽하게 포획하려면 어떻게 해야 할까요? 아주 단순무식한 방법이 있습니다.
- 탐지기를 하나만 던지는 것이 아니라, 사인파 탐지기와 코사인파 탐지기를 동시에 던지는 것입니다.

1. 코사인파로 내적을 구한다. (가로축의 결과)
2. 사인파로 내적을 구한다. (세로축의 결과)
3. 피타고라스의 정리($a^2 + b^2 = c^2$)를 이용해 두 결괏값을 합친 진짜 크기(Magnitude)를 구한다.

- 신호가 어떻게 엇갈려 있든, 코사인 탐지기를 비껴가면 사인 탐지기에 걸리고, 사인 탐지기를 비껴가면 코사인 탐지기에 걸리게 됩니다. 이 **쌍끌이 어선** 전략이 바로 푸리에 변환의 진짜 정체입니다.

## 3. 허수(j)의 등장: 두 개의 값을 담는 마법의 주머니

- 사인과 코사인을 매번 따로 계산해서 변수에 담으려면 코드가 너무 지저분해집니다. 이때 천재 수학자 오일러가 기가 막힌 아이디어를 냅니다.

> "실수 축에는 코사인을 담고, 상상 속의 축(허수 축)에는 사인을 담아서 **하나의 숫자(복소수)**로 묶어버리자!"

- 이것이 그 유명한 오일러의 공식(Euler's Formula)입니다.

$$e^{j\theta} = \cos(\theta) + j\sin(\theta)$$

(참고: 공학에서는 전류 $i$와 헷갈리지 않게 허수를 $j$로 표기하며, 파이썬에서도 1j로 씁니다.)

- 이제 우리는 $e^{j\theta}$라는 복소수 지수 하나만 신호에 곱해주면, 컴퓨터가 알아서 코사인 내적과 사인 내적을 동시에(쌍끌이로) 수행해 줍니다. 복소수는 수학책에서 우리를 괴롭히던 악당이 아니라, 두 개의 데이터를 하나의 변수에 깔끔하게 담아주는 '마법의 주머니'였던 것입니다.

## 4. 이산 푸리에 변환(DFT) 수식 해부하기

- 전공 서적에 나오는 DFT의 공식은 다음과 같습니다. 수식의 공포에 쫄지 말고, 우리가 배운 내용과 1:1로 매칭해 봅시다.

$$X[k] = \sum_{n=0}^{N-1} x[n] \cdot e^{-j 2\pi \frac{k}{N} n}$$

- $x[n]$: 우리가 캡처한 입력 신호 배열 (시간 도메인)
- $X[k]$: 주파수 분석이 끝난 결과 배열 (주파수 도메인)
- $e^{-j 2\pi \frac{k}{N} n}$: 우리의 쌍끌이 어선 탐지기 (코사인 탐지기 - $j$사인 탐지기)
- $\sum$ (시그마): 파이썬의 for문을 돌며 내적(곱하고 더하기)을 하라는 뜻!

## 5. 5.5 밑바닥부터 짜는 이중 for문 DFT (Python 실습)
- 수식을 완벽히 이해했으니, 라이브러리(`np.fft`) 없이 오직 순수 파이썬 반복문만으로 세상에서 가장 정직한 DFT 함수를 쌩코딩해 보겠습니다.

```python
import numpy as np
import matplotlib.pyplot as plt

def my_dft(x):
    """
    1차원 배열 x를 입력받아 이산 푸리에 변환(DFT)을 수행합니다.
    (O(N^2)의 순수 이중 for문 구현)
    """
    N = len(x) # 배열의 총 길이 (데이터 개수)
    
    # 결과를 담을 빈 주머니 (쌍끌이 결과를 담아야 하므로 dtype=complex 로 설정)
    X = np.zeros(N, dtype=complex)
    
    # 바깥쪽 루프 (k): 어떤 주파수를 탐지할 것인가?
    for k in range(N):
        
        # 안쪽 루프 (n): 시간에 따른 배열의 원소들을 하나씩 꺼내어 내적!
        for n in range(N):
            # 오일러의 마법: 탐지기의 각도 계산
            # 수식: -j * 2 * pi * k * n / N
            angle = -1j * 2 * np.pi * k * n / N
            
            # 신호(x[n])에 탐지기(exp(angle))를 곱해서 차곡차곡 더한다 (내적)
            X[k] += x[n] * np.exp(angle)
            
    return X

# --------------------------------------------------------
# 테스트: 위상의 함정에 빠졌던 코사인파를 포획해보자!
# --------------------------------------------------------
# 1초 동안 100번 샘플링
t = np.linspace(0, 1, 100, endpoint=False)

# 4장에서는 실패했을, 90도 밀려난 5Hz 코사인파!
mystery_signal = np.cos(2 * np.pi * 5 * t) 

# 우리가 만든 DFT 함수 실행
spectrum_complex = my_dft(mystery_signal)

# 복소수 주머니에서 피타고라스 정리로 진짜 크기(Magnitude)만 꺼내기
# np.abs()가 실수부^2 + 허수부^2에 루트를 씌워줍니다.
spectrum_magnitude = np.abs(spectrum_complex)

# 그래프 시각화 (앞의 절반만 그립니다. 나이퀴스트 정리 때문에 뒤는 대칭입니다)
plt.figure(figsize=(10, 4))
plt.stem(spectrum_magnitude[:50], basefmt="k-", linefmt="#2ecc71", markerfmt="go")
plt.title("My Custom DFT Result (Phase Trap Bypassed!)")
plt.xlabel("Frequency Index (k)")
plt.ylabel("Magnitude")
plt.show()
```

(실행 결과)
- 코드를 실행해 보세요! 4장의 단순 내적 탐지기였다면 0이 나왔을 코사인파 신호인데도 불구하고, 우리가 짠 my_dft 함수는 인덱스 5 (5Hz 위치)에 거대한 막대기를 우뚝 세워냅니다.
- 복잡한 시그마($\sum$)와 자연상수($e$), 허수($j$)가 얽힌 공포스러운 수식이 사실은 파이썬의 이중 for문(for k in... for n in...)에 불과했다는 사실을 내 손으로 직접 증명해 낸 것입니다!

## Summary
- 사인파 하나만으로는 타이밍(위상)이 어긋난 신호를 찾을 수 없다.
- **복소수($j$)** 와 **오일러 공식** 을 사용하면 코사인과 사인을 하나의 변수(쌍끌이 어선)로 묶어 완벽한 탐지기를 만들 수 있다.
- DFT 수식의 본질은 **O(N²)** 의 이중 for문으로 이루어진 무식하지만 확실한 내적 계산기다.
