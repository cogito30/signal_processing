# Chapter 01. 신호란 무엇인가?: 세상을 배열로 담는 법
- 우리는 매일 수많은 '신호(Signal)'에 둘러싸여 살아갑니다. 아침을 깨우는 알람 소리, 스마트폰 화면의 빛, 병원에서 재는 심장 박동(ECG), 심지어 주식 시장의 가격 변동까지. 이 모든 것이 신호입니다.

- 신호처리(Signal Processing)라는 거창한 이름을 달고 있지만, 본질은 아주 단순합니다. '시간에 따라 변하는 어떤 값을 유의미하게 분석하고 조작하는 것'입니다. 하지만 우리가 물리적인 빛이나 소리를 컴퓨터 안으로 직접 쑤셔 넣을 수는 없습니다. 세상의 물리 법칙을 컴퓨터가 이해할 수 있는 데이터 타입으로 번역하는 과정이 필요합니다.

- 이 장에서는 복잡한 수학 공식 속에 숨겨진 신호의 진짜 정체를 밝히고, 파이썬(Python)과 넘파이(NumPy)를 통해 물리적 세상을 1차원 배열로 옮겨 담는 첫걸음을 떼어보겠습니다.

## 1. 아날로그와 디지털: 연속(Continuous)과 이산(Discrete)
- 신호처리를 배우다 보면 가장 먼저 마주치는 단어가 바로 '연속(Continuous)'과 '이산(Discrete)'입니다. 수식과 기호가 난무하기 전에, 직관적인 비유로 두 개념을 구분해 보겠습니다.

- 연속 신호 (아날로그): 미끄럼틀
  - 자연계의 시간은 끊기지 않고 부드럽게 흐릅니다. 바이올린 현이 튕겨서 만들어내는 파동은 무한히 쪼갤 수 있는 시간 속에 존재합니다. 1초와 1.1초 사이에는 1.05초가 있고, 그 사이에는 1.001초의 데이터가 반드시 존재합니다. 수학에서는 이를 시간 변수 $t(time)$를 사용하여 연속 함수 $f(t)$ 로 표현합니다.

- 이산 신호 (디지털): 계단
  - 하지만 컴퓨터의 메모리는 유한합니다. 무한한 연속 신호를 하드디스크에 그대로 담을 수는 없습니다. 그래서 우리는 일정한 시간 간격마다 신호의 값을 '찰칵찰칵' 사진 찍듯 기록합니다. 이렇게 뚝뚝 끊어진 징검다리 같은 데이터를 이산 신호라고 합니다. 수학에서는 정수형 인덱스 $n$을 사용하여 $x[n]$으로 표현합니다.

- 핵심 개념: **샘플링(Sampling)**
  - 연속적인 아날로그 신호에서 일정한 간격으로 값을 추출하여 이산 신호로 만드는 과정을 '샘플링'이라고 합니다. 3장에서 깊게 다루겠지만, 세상의 모든 디지털 오디오(mp3, wav)는 이 샘플링을 거친 결과물입니다.

## 2. 코드로 보는 신호의 본질: 결국 배열(Array)이다
- 전공 서적을 펼치면 이산 신호를 다음과 같은 수식으로 정의하곤 합니다.
$$x[n] = \{0.0, 0.5, 0.86, 1.0, 0.86, 0.5, 0.0, -0.5, \dots\}$$

- 수학 기호의 압박에 벌써 책을 덮고 싶어질 수 있지만, 프로그래머의 눈으로 이 수식을 다시 해석해 봅시다. 저 중괄호 $\{ \ \}$ 안의 숫자 나열은 파이썬의 리스트(List) 혹은 넘파이 1차원 배열(NumPy 1D Array)과 정확히 1:1로 대응됩니다.

- 수학자들이 말하는 변수 $n$은 그저 배열의 인덱스(Index)일 뿐입니다!
  - 수학의 $x[0]$ $\rightarrow$ 파이썬의 x[0] (값: 0.0)
  - 수학의 $x[3]$ $\rightarrow$ 파이썬의 x[3] (값: 1.0)
  - 수학의 $x[n-1]$ $\rightarrow$ 파이썬의 x[n-1] (바로 이전 인덱스의 값)
  
- 이 사실을 깨닫는 순간, 신호처리 모델링의 거대한 장벽 하나가 무너집니다. 앞으로 우리가 이 책에서 다룰 모든 필터(Filter), 푸리에 변환(FFT), 스펙트로그램, 심지어 딥러닝 모델의 입력값까지. 그 모든 것의 실체는 결국 숫자들이 길게 늘어선 넘파이 배열에 불과합니다.

## 3. 신호를 구현해보자
- 이제 직접 코드를 작성하며 머릿속의 개념을 모니터 위로 끄집어내 보겠습니다. 아주 간단한 파동(사인파)을 '연속적인 느낌'과 '이산적인 느낌'으로 각각 생성하고 시각화할 것입니다.

- 실습을 위해 배열 연산의 근본인 numpy와, 신호를 눈으로 보게 해 줄 matplotlib 라이브러리를 사용합니다.

```python
import numpy as np
import matplotlib.pyplot as plt

# --------------------------------------------------------
# 1. 시간 축(Time Axis) 만들기
# --------------------------------------------------------
# 연속 신호를 흉내 내기 위해 0초부터 1초까지 1000개의 점으로 아주 촘촘하게 쪼갭니다.
# 컴퓨터는 완벽한 연속을 표현할 수 없으므로, 점이 아주 많으면 연속된 선처럼 보입니다.
t_continuous = np.linspace(0, 1, 1000)

# 이산 신호는 0초부터 1초까지 단 15번만 채집(Sampling)합니다.
t_discrete = np.linspace(0, 1, 15)

# --------------------------------------------------------
# 2. 가상의 신호(주파수가 2Hz인 사인파) 생성
# --------------------------------------------------------
# np.sin()을 사용하여 시간에 따른 진폭(Amplitude)을 계산합니다.
# 2 * np.pi * 2 * t : 1초에 2번 진동(2Hz)하는 파동을 의미합니다. (자세한 건 2장에서 다룹니다!)
signal_continuous = np.sin(2 * np.pi * 2 * t_continuous)
signal_discrete = np.sin(2 * np.pi * 2 * t_discrete)

# --------------------------------------------------------
# 3. 그래프로 신호 시각화하기
# --------------------------------------------------------
plt.figure(figsize=(12, 5))
plt.style.use('seaborn-v0_8-whitegrid') # 깔끔한 그래프 스타일 적용

# [왼쪽 그래프] 아날로그 신호 (Continuous)
plt.subplot(1, 2, 1)
# 연속 신호는 plot()을 사용하여 점들을 선으로 매끄럽게 잇습니다.
plt.plot(t_continuous, signal_continuous, color='#2c3e50', linewidth=2)
plt.title("Analog Signal (Continuous $f(t)$)", fontsize=14)
plt.xlabel("Time (seconds)", fontsize=12)
plt.ylabel("Amplitude", fontsize=12)
plt.axhline(0, color='black', linewidth=0.5) # 중심선(0) 긋기

# [오른쪽 그래프] 디지털 신호 (Discrete)
plt.subplot(1, 2, 2)
# 이산 신호는 점과 점 사이의 데이터가 없음을 명확히 하기 위해 
# 선으로 잇지 않고 막대(stem) 형태로 그립니다.
plt.stem(t_discrete, signal_discrete, basefmt="k-", linefmt="#e74c3c", markerfmt="ro")
plt.title("Digital Signal (Discrete $x[n]$)", fontsize=14)
plt.xlabel("Sample Index ($n$)", fontsize=12)
plt.axhline(0, color='black', linewidth=0.5)

# 간격 조절 후 출력
plt.tight_layout()
plt.show()
```

(코드 해설 및 결과 해석)
- 위 코드를 실행하면 두 개의 그래프가 나타납니다.

- 왼쪽 그래프 (plt.plot): 우리가 교과서나 오실로스코프에서 흔히 보던 부드러운 물결 모양입니다. 점 1,000개가 빽빽하게 이어져 있어 마치 하나의 완벽한 선처럼 보입니다. 자연계의 소리가 바로 이런 형태입니다.

- 오른쪽 그래프 (plt.stem): 듬성듬성 서 있는 빨간색 막대들입니다. 점과 점 사이(예: 3번째 점과 4번째 점 사이)에는 선이 존재하지 않습니다. 왜냐하면 컴퓨터 메모리에는 그사이의 데이터가 존재하지 않기 때문입니다.

- 신호처리 코드를 작성할 때 이산 신호를 굳이 plot()(선 그래프)이 아닌 stem()(막대그래프)으로 그리는 이유는 "우리가 다루는 데이터가 끊어져 있는 배열의 요소들이다"라는 사실을 뇌에 지속적으로 각인시키기 위해서입니다.

## Summary
- 세상의 물리적 신호는 연속적(Analog)이지만, 컴퓨터로 가져오려면 이산적(Discrete)으로 샘플링해야 한다.
- 수식에 등장하는 복잡한 이산 신호 $x[n]$은 파이썬의 1차원 넘파이 배열 x와 완벽히 같다.
- 수학의 $n$은 배열의 인덱스 `(x[0], x[1], ...)`를 의미한다.

- 우리는 이제 '배열'이라는 강력한 무기를 손에 쥐었습니다. 다음 장에서는 이 빈 배열 안에 넘파이의 수학 연산만을 활용하여 세상의 모든 소리를 만들어내는 기본 재료, '사인파(Sine)'와 '코사인파(Cosine)'를 우리 손으로 직접 합성해 보겠습니다.
