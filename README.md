# 밑바닥부터 만들면서 배우는 신호처리

## 1. 핵심 컨셉

- **블랙박스 타파:** `scipy.signal`, `librosa`, `torchaudio` 같은 라이브러리 사용을 초반에는 배제합니다.
- **오직 파이썬과 넘파이(NumPy)만:** 복소수 연산, 행렬 곱, 삼각함수 등 오직 기본 수학 연산과 NumPy만을 이용해 모든 알고리즘을 밑바닥부터 구현합니다.
- **수식의 코드화:** "이 복잡한 적분 기호가 파이썬의 `for`문 하나, 혹은 배열의 내적 연산 하나에 불과하다"는 것을 시각적으로 보여줍니다.

## 2. 목차 

독자가 점진적으로 성취감을 느낄 수 있도록 기초부터 현대적 딥러닝 모델까지 연결하는 구조입니다.

#### 1부: 신호의 세계로 입장하기 (기초 다지기)

- **1장. 신호란 무엇인가?:** 연속 신호와 이산 신호(아날로그와 디지털).
- **2장. 파동 만들기:** 순수 파이썬으로 사인파(Sine), 코사인파(Cosine) 합성하기.
- **3장. 샘플링과 나이퀴스트 정리:** 눈에 보이지 않는 소리(wav 파일)를 배열(Array)로 읽어오고 해부하기.

#### 2부: 주파수 세상으로의 여행 (핵심 알고리즘)

- **4장. 시간에서 주파수로 (푸리에 변환의 이해):** 수식에 쫄지 말자. 내적(Dot Product)으로 이해하는 직교성.
- **5장. 이산 푸리에 변환(DFT) 직접 구현하기:** $O(N^2)$의 무식하지만 확실한 방법.
- **6장. 고속 푸리에 변환(FFT) 직접 구현하기:** 쿨리-튜키(Cooley-Tukey) 알고리즘을 재귀 함수로 짜보고 속도 비교하기.

#### 3부: 신호 다듬기 (필터링)

- **7장. 합성곱(Convolution)의 진정한 의미:** 슬라이딩 윈도우로 직접 구현하는 컨볼루션.
- **8장. 노이즈 제거하기 (FIR 필터):** 이동 평균(Moving Average)부터 로우패스(Low-pass)/하이패스(High-pass) 필터 설계.
- **9장. 피드백이 있는 필터 (IIR 필터):** 상태를 기억하는 필터 만들기.

#### 4부: 오디오와 음성 인식의 기초 (응용)

- **10장. 시간에 따른 주파수 변화 (STFT와 스펙트로그램):** 2차원 이미지로 변환된 소리를 `matplotlib`으로 직접 그려보기.
- **11장. 인간의 귀를 모방하다 (멜 필터뱅크와 MFCC):** 주파수 스케일을 비선형으로 변환하는 과정 쌩코딩하기.

#### 5부: 현대적 신호처리 모델 (딥러닝과의 만남)

- **12장. 신호를 보는 인공지능 (1D CNN):** 우리가 만든 스펙트로그램이나 원시 신호를 파이토치(PyTorch)의 1D CNN과 연결해 간단한 화자 인식/음성 분류 모델 만들기.


#### 5부: 신호의 특징을 학습하는 인경신경망 (기초 딥러닝과 신호처리)

과거 수학적으로 설계했던 필터들을 신경망이 어떻게 스스로 학습하는지 연결하는 파트입니다.

- **12장. 학습하는 FIR 필터 (1D CNN):**
- **핵심:** 앞서 배운 합성곱(Convolution) 수식이 어떻게 1D CNN의 가중치(Weight) 업데이트로 변환되는지 증명합니다.
- **실습:** 센서 데이터(예: 스마트폰 가속도계)의 패턴을 분류하는 1D CNN을 넘파이(NumPy) 기반의 순전파/역전파로 직접 구현합니다.


- **13장. 상태를 기억하는 IIR 필터의 진화 (RNN과 LSTM):**
- **핵심:** 이전 상태를 기억하는 IIR 필터의 개념을 확장하여, 순차적(Sequential) 신호를 처리하는 RNN의 셀 구조를 분해합니다.
- **실습:** 주식 가격이나 심장 박동(ECG) 같은 시계열 신호의 다음 스텝을 예측하는 모델을 밑바닥부터 작성합니다.


- **14장. 신호의 노이즈를 지우는 마법 (Autoencoder와 U-Net):**
- **핵심:** 신호를 압축했다가 복원하는 과정에서 의미 있는 특징만 남기는 원리를 배웁니다.
- **실습:** 잡음이 섞인 음성 스펙트로그램 이미지에서 노이즈(배경음)만 깔끔하게 제거하는(Denoising) U-Net 구조를 축소판으로 만들어봅니다.

#### 6부: 현대 신호처리의 최전선 (SOTA 모델의 해부)

최근 3~4년 사이 신호처리 학계와 산업계를 지배하고 있는 핵심 아키텍처들의 구조를 파헤칩니다.

* **15장. 멀리 있는 신호까지 바라보기 (WaveNet과 Dilated CNN):**
* **핵심:** 초당 수만 개의 샘플(음성 파형)을 처리하기 위해 수용 영역(Receptive Field)을 기하급수적으로 넓히는 팽창 합성곱(Dilated Convolution)의 묘미를 알아봅니다.
* **실습:** 구글의 WaveNet 구조를 모방하여, 이전 파형 데이터를 바탕으로 다음 파형을 생성(Generate)하는 간단한 오디오 합성 모델을 짭니다.


* **16장. 전체 신호의 맥락을 읽다 (Transformer와 Self-Attention):**
* **핵심:** 자연어 처리를 제패한 트랜스포머가 어떻게 신호(Audio/Time-series) 처리까지 장악했는지 어텐션(Attention) 메커니즘을 내적으로 뜯어봅니다.
* **실습:** 음성 스펙트로그램을 여러 조각(Patch)으로 나누어, 어떤 주파수 대역이 다른 대역과 연관이 있는지 어텐션 맵(Attention Map)을 직접 시각화해 봅니다 (Audio Spectrogram Transformer의 기초).


- **17장. 전통 신호처리와 딥러닝의 위대한 융합 (DDSP):**
* **핵심:** 블랙박스인 딥러닝과 직관적인 전통 DSP(오실레이터, 필터)를 결합한 미분 가능한 디지털 신호처리(Differentiable DSP)의 개념을 다룹니다. 이 책의 앞부분(1~3부)과 뒷부분(5~6부)을 완벽하게 이어주는 피날레입니다.
- **실습:** 신경망이 직접 파형을 찍어내는 대신, '사인파의 주파수'와 '필터의 강도'를 조절하는 파라미터를 출력하여 신호를 합성하게 만들어 봅니다.


## 3. Tip

1. **시각화(Visualization):** 신호처리는 눈으로 보일 때 가장 직관적입니다. 코드가 실행될 때마다 `matplotlib`으로 타임 도메인과 주파수 도메인 그래프가 어떻게 변하는지 보여줍니다.
2. **실제 데이터를 활용:** 임의로 생성한 노이즈 배열보다는, **직접 녹음한 목소리**나 **심장 박동(ECG) 데이터** 등 실제 와닿는 데이터를 다룹니다.
3. **병목 현상 경험:** 처음에는 느린 DFT를 짜서 1초짜리 오디오를 변환하는 데 몇 초가 걸리는지 보여주고, 그다음 FFT를 적용해 0.01초 만에 끝나는 것을 보여줍니다.
4. **과감한 생략과 집중:** 최신 모델(Transformer, DDSP 등)을 순수 NumPy로 처음부터 끝까지 구현하면 수천 줄이 넘어갈 수 있습니다. 5부까지는 '순수 파이썬/넘파이' 기조를 유지하되, **6부부터는 PyTorch 같은 프레임워크를 도입**하여 구조(Architecture) 설계와 개념 이해에 집중합니다.
5. **전통 알고리즘과의 비교 (A/B 테스트):** 8장에서 만든 '전통적인 하이패스 필터'로 노이즈를 제거한 결과와 14장에서 만든 '딥러닝 U-Net'으로 노이즈를 제거한 결과를 시각적(스펙트로그램) 및 청각적으로 비교하는 섹션이 있으면 "왜 현대 모델을 써야 하는가?"에 대한 필요성을 보여줍니다.
